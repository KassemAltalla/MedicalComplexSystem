# تصميم واجهات العيادة (Clinic Frontend Design)

## 1. الهيكلية والتوجيه (Architecture & Routing)
- سنقوم بتهيئة `next-intl` لإدارة التوجيه باللغتين (Routing Middleware).
- بنية الملفات ستنتقل لدعم مجلد `[locale]` كالتالي:
  - `src/app/[locale]/layout.tsx`
  - `src/app/[locale]/clinics/page.tsx`
  - `src/app/[locale]/clinics/new/page.tsx`
- تحديد اتجاه العرض (RTL/LTR) بناءً على قيمة الـ `locale` الممررة من المسار.

## 2. التصميم المرئي (Visual Design & Shadcn UI)
- الاعتماد على مكتبة `shadcn/ui` لتوفير مكونات قياسية وموثوقة (مثل Button, Input, Table).
- تخصيص ألوان `shadcn` في `globals.css` لتدعم مظهراً فخماً (Premium Design) يعتمد على تدرجات الأزرق الداكن والرمادي الأنيق.
- إضافة مظهر "Glassmorphism" للبطاقات باستخدام أصناف Tailwind (مثل `backdrop-blur-md bg-white/10`).

## 3. الواجهات (Pages)
### أ. صفحة إدارة العيادات (`/clinics`)
- جدول (Table) يعرض قائمة العيادات المسترجعة من قاعدة البيانات عبر استعلام (Server Component).
- يضم الجدول أعمدة: اسم العيادة (بناءً على اللغة الحالية)، أيام العمل، وأوقات الدوام.
- رأس الصفحة يحتوي على عنوان وزر "إضافة عيادة" بتصميم بارز ينتقل بالمستخدم إلى صفحة الإنشاء.

### ب. صفحة إضافة عيادة (`/clinics/new`)
- نموذج (Form) فخم يدعم التحقق المسبق عبر (React Hook Form + Zod).
- الحقول المطلوبة:
  - اسم العيادة (عربي)
  - اسم العيادة (إنجليزي)
  - أيام العمل (مؤقتاً كمدخل نصي أو قائمة منسدلة بسيطة)
  - وقت البدء (Start Time)
  - وقت الانتهاء (End Time)
- زر للإرسال يتصل بـ Server Action `createClinic` المصمم سابقاً.
- معالجة حالات النجاح والخطأ باستخدام مكون الإشعارات `toast`.
