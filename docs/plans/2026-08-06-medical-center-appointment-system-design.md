# تصميم نظام إدارة وحجز المواعيد للمركز الطبي

## الهدف (Goal)
بناء نظام إلكتروني داخلي متكامل مخصص لكادر المركز الطبي لإدارة بيانات الأطباء، العيادات، المرضى، وحجز المواعيد بكفاءة، مع دعم كامل للغتين (العربية والإنجليزية) وتوجيه الشاشة (RTL/LTR).

## التقنيات المعمارية (Architecture & Tech Stack)
- **إطار العمل الأساسي:** Next.js 16 (App Router).
- **تعدد اللغات (i18n):** استخدام Next-intl أو إمكانيات Next.js App Router المدمجة لدعم العربية (ar) والإنجليزية (en) مع مراعاة اتجاه النصوص (RTL في العربية).
- **إدارة البيانات:** Server Actions مع Zod.
- **قاعدة البيانات:** PostgreSQL مع Prisma ORM.
- **تخزين اللغات (Localization in DB):** استخدام نوع البيانات `JSONB` في الحقول التي تتطلب ترجمة (مثل اسم العيادة والتخصص) لتخزين القيمتين `{"ar": "...", "en": "..."}` بطريقة احترافية ومرنة دون الحاجة لجداول معقدة.
- **واجهة المستخدم:** Tailwind CSS v4 مع مكونات UI جاهزة وقابلة للتخصيص (مثل shadcn/ui) تدعم بشكل كامل `dir="rtl"`.

## مخطط قاعدة البيانات (Database Schema)

### 1. الكيانات الأساسية (Core Entities)
- **Clinic (العيادة):**
  - `id`: المعرف الفريد.
  - `name`: اسم العيادة (`JSONB` لدعم اللغتين).
  - `workingDays`: أيام العمل.
  - `startTime` & `endTime`: ساعات العمل.

- **Doctor (الطبيب):**
  - `id`: المعرف الفريد.
  - `fullName`: الاسم الكامل (`JSONB` لدعم اللغتين).
  - `specialization`: التخصص الطبي (`JSONB` لدعم اللغتين).
  - `licenseId`: الرقم الوظيفي.
  - `phone` & `email`: معلومات التواصل.
  - `clinicId`: علاقة مع العيادة.

- **Patient (المريض):**
  - `id`: المعرف الفريد.
  - `fullName`: الاسم الكامل.
  - `nationalId`: الرقم الوطني.
  - `dob`: تاريخ الميلاد.
  - `phone`: رقم الهاتف.
  - `bloodType`: فصيلة الدم.
  - `medicalNotes`: ملاحظات.

- **Appointment (الموعد):**
  - `id`: المعرف الفريد.
  - `date`: تاريخ الحجز.
  - `timeSlot`: خانة الوقت.
  - `status`: حالة الموعد.
  - العلاقات: `doctorId`, `patientId`, `clinicId`.
