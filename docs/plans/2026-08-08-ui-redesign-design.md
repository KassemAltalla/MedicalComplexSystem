# تصميم واجهات النظام الطبي (Modern Medical Cyan & Deep Navy Design)

## 1. الرؤية الهندسية ونظام الألوان (Design System)
- **مجموعة الألوان الرئيسية:**
  - الأزرق الملكي الداكن (Deep Navy): `#0a1128` و `#1c2541` للخلفيات والبطاقات.
  - السيان الطبي البراق (Medical Cyan): `#00b4d8` و `#0077b6` للأزرار البارزة والمؤشرات.
  - الرمادي الفاخر: `#f8fafc` للخلفيات الفاتحة و `#94a3b8` للنصوص الثانوية.
- **تأثيرات الزجاج والحركة (Glassmorphism & Micro-animations):**
  - فئات CSS جديدة `.glass-card` و `.glass-nav` بخلفيات ضبابية وتأثيرات توهج عند التمرير (`hover:shadow-cyan-500/10`).
  - انتقالات حركية ناعمة لجميع الأزرار والمداخل.

## 2. الهيكل البصري والمكونات (Components & Layout)
- **الشريط العلوي التفاعلي (Glassmorphic Header):**
  - شريط تنقل زجاجي مثبت أعلى الصفحة يضم شعار المركز الطبي، إحصائيات سريعة، ومبدّل اللغة التفاعلي (عربي / English) مع دعم اتجاه الـ RTL تلقائيًا.
- **صفحة قائمة العيادات (`/clinics`):**
  - بطاقة ترحيبية وإحصائية في الأعلى (إجمالي العيادات، حالة النظام).
  - حقل بحث سريع وشريط أدوات مجهز بفرز وتصفية.
  - جدول تفاعلي ذو مظهر زجاجي مع شارات ملونة لأيام وساعات الدوام وحالة العيادة.
  - تصميم مخصص للـ Empty State عندما تكون القائمة فارغة لحث المستخدم على الإضافة.
- **صفحة إضافة عيادة (`/clinics/new`):**
  - نموذج زجاجي مقسّم بصريًا لسهولة الإدخال (حقول باللغة العربية بحجم واتجاه RTL مناسب، وحقول بالإنجليزية).
  - اختيار الساعات بواجهة أنيقة وأزرار تفاعلية لإرسال النموذج مع شريط تحميل (Spinner).

## 3. خطة التحقق والاختبار (Verification & Efficiency)
- التأكد من متطلبات التوافق للغتين (Arabic RTL & English LTR).
- اختبار التجميع والعمل بدون أخطاء عبر `npm run build`.
- التأكد من تجربة المستخدم والسلاسة عبر تصفح الواجهة.
